Ferramentas necessárias para desenvolvimento web

  • Computador ou notebook
  • VS Code
  • Navegador web
  • HTML5 e CSS
  1. Instalar o VS Code no computador ou notebook.
  2. Criar um arquivo HTML e estruturar a página.
  3. Adicionar os conteúdos, textos e elementos necessários.
  4. Salvar o arquivo e abrir no navegador pra testar.
